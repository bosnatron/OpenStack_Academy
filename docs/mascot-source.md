# Slackware penguin

Academy serves `public/images/slackware-mascot.svg` locally. The shared layout
includes it on the welcome screen, chess entrance, unlocked index and lessons;
the standalone license page uses the same file and bottom-left placement.

This is the Slackware penguin with pipe, using Wyatt8740's SVG redraw dated
28 July 2014. Its source is
[Wikimedia Commons: Slackware-mascot.svg](https://commons.wikimedia.org/wiki/File:Slackware-mascot.svg).
The source page permits use, modification and redistribution for any purpose,
including commercial use (copyrighted free use). Academy does not claim the
artwork as its own.

The unchanged SVG was obtained from the public
[Ridhsuki/linux-notes mirror](https://github.com/Ridhsuki/linux-notes/blob/650ffb2bd1cf0890b6a14d3f99527ee1869f4bb9/linux-logo/Slackware-mascot.svg)
at commit `650ffb2bd1cf0890b6a14d3f99527ee1869f4bb9`.
Its Git blob SHA is `843b528b0451b52f048dac24bf94ae748a5a0207`.
It contains no scripts, embedded images or external resource links.

The previous shared layout used a remote Wikimedia PNG. Failed or blocked
image requests could leave the penguin missing even though its layout element
was present. The local SVG removes that dependency for every Academy page.
